# Lumen - Private AI Companion NFT on NEAR

Lumen is a personal AI companion that lives as an NFT on NEAR.

- Private conversations via **NEAR AI Cloud TEEs**
- Can hold value and execute actions via **NEAR Intents**
- Hard spending limits controlled by the owner
- True ownership (NEP-171 NFT)
